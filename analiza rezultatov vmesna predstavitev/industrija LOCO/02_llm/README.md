# LOCO: vsi shranjeni LLM odgovori

Vseh 4860 položajev je shranjenih v 810 svežnjih pod `responses/`, skupaj z
napakami in preskoki. Zamrznjeni vhodi, dejanski prompti ter celotni odzivi in
metapodatki ostanejo ohranjeni. Odprite `index.html` za obstoječi pregledovalnik.

Po zadnjem navodilu je preverjen samo obstoj datotek. Stare agregatne tabele,
primerjave in obrazci so vmesni posnetki, niso ponovno izračunani. Novi testi,
ponovitve, analize in poročila niso izvedeni. Podrobnosti: [../README.md](../README.md).
