# Enoslikovni tehnični preizkus

Vhod: `results models/lilocbench/images/view-000001.png`, že objavljena slika LILocBench. Izvor in licenca sta ohranjena v prvotnem naboru ter LICENSE-DATA.md/CITATION.bib.

`initial/` ohrani prvi tehnični zapis z napako EOS validatorja. Odgovor modela se ni spreminjal. `completed/` vsebuje dokumentirano ponovno validacijo istega opisa brez novega modelnega klica, nato samo manjkajoči grounding in en Qwen odgovor. Skupaj tri različne generacije na eni sliki. `resume.txt` dokazuje 0 novih inferenc pri nadaljevanju. To so pregledne kopije artefaktov; izvirne začasne mape ostajajo lokalno. Ni ročnih ocen ali analize pravilnosti.
