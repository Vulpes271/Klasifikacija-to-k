# Vhodne slike

Aktivni pipeline sprejme poljubno lokalno RGB mapo z `--input`. Nova vhodna mapa
je lahko `data/input/`; njena vsebina ostaja izključena iz Gita.

Ohranjene slike LILocBench so v `results models/lilocbench/images/`, skupaj z
licenco in izvorom v nadrejeni mapi. Stari izbori THUD/LOCO in njihova navodila
so v objavljeni veji `archive/experiments-before-prune-2026-11-05`.

Lokalnih nesledenih podatkov čiščenje aktivne veje ni odstranjevalo.
